# Project Synopsis

## Project Title
ExpenseHub — Offline-First Personal and Shared Finance Management Mobile Application

## Team Members
- Sanghratna More
- Om Singh

## Course
BCA — Semester 5

## Introduction
ExpenseHub is a mobile application that helps users manage personal income, expenses, and shared group expenses. Users can track daily spending, view financial dashboards, create groups for trips or shared accommodation, split expenses, and settle balances.

## Problem Statement
People often fail to track daily expenses, and groups such as friends on a trip or flatmates in a PG face confusion while dividing and settling shared expenses. Manual calculation is time-consuming and prone to errors. Also, users may not always have internet access.

## Proposed Solution
ExpenseHub allows users to add personal and shared expenses even without internet. Offline expenses are stored locally on the mobile device using SQLite and automatically synchronized with the central Spring Boot server when internet becomes available.

## Objectives
- To track personal income and expenses.
- To provide a dashboard with monthly financial summaries.
- To create groups for trips, PG/flat expenses, or events.
- To split group expenses equally among members.
- To calculate member balances and settlements.
- To support offline expense entry and automatic synchronization.
