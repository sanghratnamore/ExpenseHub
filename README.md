# ExpenseHub

ExpenseHub is a personal and group finance management app built with Flutter and Spring Boot.

## Features
- Personal income and expense tracking
- Group expenses and settlements
- Budget tracking
- Recurring transactions
- Notifications
- Transaction search and filters
- Recurring transaction history
- Monthly and group reports

## Tech Stack
- Flutter
- Spring Boot
- MySQL / your database
- Firebase Cloud Messaging
